# 0.5.0-3：配置领取使用当前 NAS 内网 HTTPS 地址

通过 https://192.168.10.10:5001 登录 DSM 并打开套件后，手机二维码使用该内网地址，电脑普通下载继续使用当前页面的同源地址。VPN 配置里的服务器域名不变，外部只需 UDP 500/4500，配置领取不再依赖公网门户。手机需要在可达 NAS 的内网，并信任 NAS 的 HTTPS 证书。

领取令牌绑定生成时的精确来源，跨来源请求不会消耗有效令牌；仍然 5 分钟、单次使用，取消/解绑/重启失效。正式环境拒绝通过明文 HTTP 生成二维码。需要从内网 IP 打开门户后重新生成旧二维码；从域名入口生成的二维码则使用该域名入口。

新增 iOS/Android 内网领取和 VPN 域名保持不变的回归测试。此版本已于 2026-11-06 更新到 NAS，套件中心显示 0.5.0-3、已启动，门户网关就绪；手机内网扫码领取仍需实机验收。

# SynoVPN

群晖 DSM 上的轻量 IKEv2 VPN 自助套件：Go、SQLite、strongSwan 证书认证、DSM 原生登录、手机扫码领取配置和管理员设备管理。

当前版本 **0.5.0-7**，已在 **SA6400 / DSM 7.4.1-90080 Update 1 / epyc7002** 安装运行。iPhone 移动数据连接和用户主动解绑已验证；管理员身份、全局设备列表及搜索筛选已实机验证。跨用户管理员解绑、不同客户端系统等验证边界见 [VALIDATION.md](VALIDATION.md)。这是开发预览版。

0.5.0-6 支持管理员按 DSM 用户设置内网、公网 IPv4 / CIDR 允许列表，不设固定规则条数上限；自定义规则覆盖默认规则，空列表拒绝访问。2026-11-09 已升级 NAS；首次启动需套件中心修复，随后套件已启动、网关就绪，DSM 用户规则页面正常加载。已通过完整 Go 测试、go vet 及手机下载回归；客户端与隔离实机验证边界见 [docs/USAGE.md](docs/USAGE.md) 和 [VALIDATION.md](VALIDATION.md)。

## 本地运行

需要 Go 1.26+。在项目根目录运行：

```sh
go test ./...
go vet ./...
go run ./cmd/synovpn demo --data ./var/demo --listen 127.0.0.1:8787
```

浏览器访问 http://127.0.0.1:8787。演示只监听本机，使用假身份与隔离 PKI，不建立 VPN。演示账号有管理员视图，仅用于预览。生产入口必须通过 DSM 原生会话验证。

## 文件结构

| 目录 | 内容 |
|---|---|
| `cmd/synovpn` | CGI 桥、Web、生产引擎和本地演示入口 |
| `cmd/vici-probe` | 真实 strongSwan/VICI 签发和撤销自检 |
| `internal` | 认证、数据库、证书、配置生成、引擎、网络、Web 与测试 |
| `packaging` | DSM 生命周期、权限、安装向导、菜单、容器资源 |
| `tools` | 编译、静态引擎构建、GRO 兼容补丁及打包工具 |
| `vendor` | Go 依赖源码，可离线编译 |
| `runtime/amd64` | 已在 NAS 自检的静态 charon、上游源码归档与许可证 |
| `licenses` | 第三方许可证 |
| `dist` | 当前发行 SPK 和 SHA-256；重新构建的包也输出到这里 |
| `docs` | 构建、部署、操作、验证和历史资料 |

设备关联的是 DSM 用户与独立证书，不是不可复制的硬件绑定。VPN 使用证书，不使用群晖密码。Web SSO 只负责门户登录。普通用户只管理自己设备；管理员组成员有单独的全局列表和解绑入口，不提供他人的私钥下载。

`dist` 中随附的 SPK 是已经部署的发行包。重新打包会纳入当前文档等内容，SHA-256 可能改变，请使用同次构建生成的校验文件。
