# 排障

## 页面无法识别用户 / 返回 HTML 而非 JSON

先重新登录当前地址的 DSM，从主菜单重开套件。每个地址的 Cookie/会话独立，不能把公网令牌复制到内网 URL。0.4.0-3 起支持原生 CGI 当前内网来源及绑定来源的 CSRF，并把非 JSON 返回转换成清楚的错误提示。不要关闭 CSRF 或信任浏览器用户名头来绕过错误。

## 一直连接中 / 最后失败

先使用手机移动数据复现并记录时间，检查 Container Manager → synovpn-engine → 日志：

- 没有对应请求：核对公网 DNS、UDP 500/4500、路由器及 DSM 防火墙、运营商入站条件；网页能访问不代表 UDP 可达。
- IKE_SA_INIT 失败：核对客户端类型、算法和服务端身份。
- IKE_AUTH 完整性错误：旧包在 DSM 5.10.55+ 上出现 UDP GRO 合并报文兼容问题，0.4.0-2 起引擎已包含 socket 级修复。不要全局关闭网卡功能或降低证书验证。
- 证书错误：核对是否已解绑/过期、配置是否来自此 NAS、服务器域名是否一致；不能只看 IKE_SA established 就认为手机已完成连接。

套件日志在 `/var/packages/SynoVPN/var/log/`。不要公开 Cookie、SynoToken、engine.token、密钥文件或含私钥的配置包。

## 在线显示不一致

保持手机连接，关闭页面弹窗、切回可见标签页、点击刷新，对照引擎 DPD/会话日志。0.4.0-4 增加仅在状态变化时记录的会话诊断。曾观察到重连后页面显示 1 台在线，但先前不一致的根因未完全确定，不能把增加日志描述成已定位的代码修复。

## 连接成功但内网不通

分别检查目标 IP、目标服务端口、内网 DNS、允许路由、VPN 池与本地 Wi-Fi 是否重叠，以及目标设备防火墙。当前仅提供配置内的 IPv4 内网分流，不接管互联网或 IPv6。不要通过删除证书卷或放开全部防火墙排障。

## 套件无法启动

确认 Container Manager 正常、镜像获取可用、UDP 端口无冲突和存储空间健康。查看套件安装/启动日志及引擎日志。若升级后引擎已启动但套件显示失败，可在套件中心尝试“修复”，然后重新检查服务就绪；多次失败需依据日志排查，不能仅反复重装。XFRM interface 探测失败不一定表示 policy-based IPsec 不可用；需结合实际初始化、策略和隧道日志判断。

## 管理员入口不出现

关闭旧页面并从 DSM 主菜单重开，确认本地管理员组和套件允许组成员身份。角色每次 API 请求重新校验；浏览器不能通过 URL 或本地存储提升权限。

## 构建失败

缺少 Go/Python：安装所需工具或通过 --go 指定。缺少引擎：恢复随附的准确运行时或进行 Docker 完整构建。复用哈希不符：不要更改准入值绕过，先执行真实引擎检查。自检需要自己的容器 NET_ADMIN，不允许把宿主网络作为“解决方式”。静态 PIE 同样可用，检查 ELF 的 PT_INTERP 而不是依赖 file 输出文字。
