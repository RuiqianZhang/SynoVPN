# 用户与管理员使用

## 个人设备

1. 登录 DSM，从主菜单打开 SynoVPN。公网域名或实际内网 HTTPS 地址均可；不要直接收藏不带 DSM 启动上下文的 CGI 地址。
2. 点击“添加设备”，填写易识别的名称并选择真实系统。默认每用户最多 5 台未解绑设备，证书 90 天到期。
3. 下载配置或对手机使用“手机扫码安装”，按系统提示安装。连接 VPN 使用设备证书，无需群晖账号密码；首次证书导入口令或系统解锁密码不等于 VPN 登录密码。
4. 不再使用时在页面解绑，撤销证书及复制件并断连。失败时可能显示“解绑处理中”，不要当作已完成；系统恢复后自动重试。

列表、下载、签发和个人解绑都按 DSM UID + 用户名隔离。配置可以复制，不是硬件锁定；安装后妥善删除下载副本。群晖禁用用户并不等于自动撤销已签发 VPN 证书，此版本管理员应另外解绑该用户设备。

## 手机扫码

二维码本机生成，5 分钟、一次领取。持有人可领取该设备的证书私钥配置，勿转发或共享截图。重新生成、关闭作废、到期、解绑、门户重启会令旧链接失效。领取链接使用生成二维码时的 NAS HTTPS 入口。请通过内网 IP 登录 DSM 并重新生成二维码，手机需在内网访问该地址；VPN 服务器域名仍保持不变。

- **iPhone / iPad**：相机扫码，用 Safari 打开领取页。允许下载描述文件，在“设置 → 通用 → VPN 与设备管理”安装，输入系统解锁密码并确认。之后从系统 VPN 开关连接。
- **macOS**：打开下载的 mobileconfig，在系统设置中的描述文件/设备管理确认安装，再使用系统 VPN。设置位置依系统版本变化。
- **Windows**：解压 ZIP，阅读说明，双击包内 `install-windows.cmd`，点击 UAC 管理员授权。核对 CA 指纹并确认。本 NAS 已存在另一张有效设备证书时脚本会停止，避免选错身份；先解绑并由管理员手动移除旧客户端证书。
- **Android**：解压 ZIP，按 `certificate.json` 中导入口令安装设备 P12 和服务器 CA，在支持的系统选择 IKEv2/IPSec RSA，并填写包内本地/远程标识。系统/厂商差异较大，缺少该选项时不保证免装客户端。

扫码负责传递配置，不能代替系统安装确认，也不能网页一键自动拨号。Apple 配置未使用商业签名，可能显示未签名提示，需自行确认来源。已验证 iPhone 实机连接；其余平台的系统兼容性仍需验收。

## 管理员

属于 DSM 本地 `administrators` 组、且通过套件允许用户组检查的用户，可在顶部切换“管理员 · 设备管理”。当前默认允许组为 users。服务器每次请求重新校验管理员权限；不根据用户名是不是 admin 来授权。不承诺 AD/LDAP 账户支持。

管理页显示全部用户设备及归属，支持按用户/设备搜索和状态筛选。“仅在线”显示当前引擎标记的在线连接。选中“解绑并断连”后会显示用户名和设备名，确认后撤销该设备。管理页不提供下载他人私钥的能力；个人视图仍只显示自己的设备。

管理员解绑在 SQLite 记录操作人、时间、目标设备，保留的设备记录可查询目标用户。审计记录当前保存在数据库，尚未提供专门的审计查询/导出 UI。

页面可见时约每 10 秒刷新；弹窗打开或标签页隐藏时自动刷新暂停。需要即时状态时关闭弹窗并点击刷新。引擎不可用时应显示未知，不要用“未连接”来判断撤销是否完成。设备全部解绑后在线数 0 是预期结果。


## Android 扫码下载（0.5.0-4）

从内网 HTTPS 打开套件，生成 Android 设备二维码。手机在内网扫码，点击“领取设备配置”，等待页面显示已接收的字节数，再点击“保存 Android 配置包”。此时保存的是浏览器已收到的本地文件，不会再次领取服务器令牌。下载后解压，按使用说明安装。若扫码应用不支持保存，请用系统浏览器或 Chrome 打开新生成的二维码；不要重试已消费的旧码。

页面显示错误时按提示检查内网 HTTPS 可达性和证书信任。服务端令牌仍然单次、5 分钟有效；领取后本页临时副本在离开页面或 5 分钟后清除，已保存文件需要自行删除。


## Windows 10 连接失败排查

请先在失败机器上连接一次并记录系统错误码、失败时间及 Windows 版本。需要更多信息时，解压 `dist/SynoVPN-Windows-diagnostics.zip`，双击 `diagnose-windows.cmd` 并确认 UAC。无需手动以管理员打开 PowerShell。脚本只读，不会安装证书、改变 VPN 或自动连接，报告保存在同目录并自动用记事本打开；可先提供 Windows Build 和 RasClient ErrorCode。请勿发送 P12、证书导入口令或设备私钥。


### DNS 返回 198.18.x.x / 198.19.x.x

这属于 198.18.0.0/15 保留测试网段，常见于 Clash/Mihomo Fake-IP。先核实本机或路由器代理是否返回虚拟地址；VPN 公网域名应解析至 NAS 实际公网入口。代理中需同时排除该域名的 Fake-IP 和 VPN 流量接管，仅设置 DOMAIN,DIRECT 未必会返回真实地址。根据实际配置模式合并 fake-ip-filter 和直连规则，不能覆盖原有整份 DNS/路由配置。修改后清理 DNS 缓存再测试；不要将 VPN 服务器地址替换为内网领取 IP 或虚拟 Fake-IP。


### 持续错误 87 的认证采集

常规报告无法确认私钥访问和认证初始化错误时，使用 `dist/SynoVPN-Windows-auth-trace.zip`。解压双击 `trace-auth.cmd`，确认 UAC；只有一条 SynoVPN 连接时自动选择，否则输入列表编号。工具临时启用可用的 Windows 证书/认证日志，尝试拨号一次、生成 `SynoVPN-auth-trace-日期时间.txt` 并恢复日志开关，不改证书、VPN 算法或代理设置。管理员身份下的私钥签名探测不能代替 SYSTEM/IKEEXT 服务身份验证。成功拨号会保持连接。报告包含该短时间窗证书/认证事件，仅提供给排查人员。


## 删除设备记录

先解绑，等待状态变为“已解绑”，点击“删除记录”并确认。记录从列表移除，不再占列表空间；撤销状态和审计仍保留。管理员设备管理中可清理其他用户的已解绑记录。活动或解绑处理中不能直接删除，避免清理记录绕过撤销。
